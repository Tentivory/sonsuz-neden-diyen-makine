# Sonsuz Neden Diyen Makine

## Bu Ne Lan?

Bu, dünyanın en ciddiye alınması gereken ama aslında tamamen saçma bir yazılım projesidir. İnsanlığın en büyük sorusuna ("Neden?") sonsuz cevap üreten devrim niteliğinde bir makinedir.

### Özellikler (Abartılı):
- Sonsuz döngüde "neden?" üretir. Bilimsel olarak kanıtlanmıştır (değil).
- Rastgele absürt açıklamalar yapar. Nobel ödülü adayıdır (hayal).
- Ctrl+C ile durur, ama neden durasın ki?
- Python 3 ile çalışır. Başka hiçbir şeyle çalışmaz, çünkü neden?

### Nasıl Kullanılır?
```bash
python neden.py
```
Sonra otur ve izle. Hayatın anlamını bulamayacaksın ama eğleneceksin. Belki de neden eğleniyorsun diye soracaksın.

### Uyarılar:
- Bu programı çalıştırırsan beynin "neden?" demeye başlayabilir.
- Sorumluluk kabul etmiyoruz, çünkü neden?
- Gerçekten çalışır. Test ettik. Çok ciddi test ettik. (yalan)

### Katkıda Bulunma:
Pull request atabilirsin ama neden atarsın? Cevabın yoksa atma.

### Lisans:
MIT ama aslında "neden lisans?" diye sormaktadır.
